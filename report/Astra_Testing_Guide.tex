\section{Stage 2: OS Deadlock Laboratory \& Fault-Tolerant Checkpointing}

\subsection{Step 4: OS Deadlock Laboratory Simulation (Banker's Algorithm \& WFG Visualizer)}
Execute the full 7-section academic deadlock detection, circular wait analysis, and preemption lab:
\begin{lstlisting}[style=cmdstyle]
./build/astra deadlock demo
\end{lstlisting}
\begin{itemize}[leftmargin=*,itemsep=1.5pt,topsep=1pt]
    \item \textbf{Section [1] Process State \& Contention Matrix:} Shows \code{Job-Alpha} holding CPU Core 0 and waiting for GPU, while \code{Job-Beta} holds GPU and waits for CPU Core 0 across worker thread slots.
    \item \textbf{Section [2] Shared Resource Inventory:} Evaluates contention load ($200\%$ over-subscribed) across CPU Core 0 and the detected \textbf{NVIDIA GeForce RTX 3050 Laptop GPU}.
    \item \textbf{Section [3] Deadlock Risk Analysis:} Mathematical contention risk meter calculated as:
    $$\text{Risk}(J) = 1.0 - \frac{\text{Available}_r}{\text{Need}_r} = 1.0 - \frac{0}{1} = 100.0\% \quad \text{[CRITICAL CONTENTION / 0.0\% SAFETY MARGIN]}$$
    \item \textbf{Section [4] Wait-For Graph (WFG) Visualization:} Renders the circular ASCII hold-and-wait dependency. Triggers 3-color DFS recursion: \code{CIRCULAR WAIT DETECTED IN DFS: [Job-Beta] -> [Job-Alpha] -> [Job-Beta]}.
    \item \textbf{Section [5] Dijkstra's Banker's Safety Matrix:} Proves Available $= [0, 0]$, Need $= [0, 1]$ and $[1, 0]$ with zero safe sequences.
    \item \textbf{Section [6] Explainable Preemption \& Victim Selection:} Evaluates cost-loss optimization function:
    $$\text{CostScore} = (P_{\text{base}} \cdot 0.70) + (\tau_{\text{sunk}} \cdot 0.30)$$
    \begin{itemize}[leftmargin=*,itemsep=0.5pt,topsep=0.5pt]
        \item \textbf{Job-Alpha (Pri 8, Sunk 1450ms):} $(8 \cdot 0.70) + (1450 \cdot 0.30) = 440.6$
        \item \textbf{Job-Beta  (Pri 2, Sunk 120ms):}  $(2 \cdot 0.70) + (120 \cdot 0.30) = \mathbf{37.4} \implies \text{\textbf{Optimal Minimal-Loss Victim}}$
    \end{itemize}
    \item \textbf{Section [7] Post-Recovery Safety Verification:} Preempts Job-Beta, releases RTX 3050 GPU back to pool, restores safety score to $100.0\%$ SAFE with provably safe execution sequence $\langle \text{Job-Alpha} \rangle$.
\end{itemize}

\subsection{Step 5: Atomic Checkpoint \& Crash Recovery (Fault Tolerance)}
Verify non-volatile checkpointing and exact resume mechanics after a process fault:
\begin{lstlisting}[style=cmdstyle]
# 1. Run compute workload configured to simulate fatal crash at step 50,000 (Target: 100,000)
./build/workloads/checkpointable_sum --target 100000 --fail-at 50000 --checkpoint-file /tmp/test.ckpt

# 2. Inspect serialized binary state checkpoint file
ls -lh /tmp/test.ckpt

# 3. Resume computation from preserved state checkpoint
./build/workloads/checkpointable_sum --target 100000 --resume --checkpoint-file /tmp/test.ckpt
\end{lstlisting}
\begin{itemize}[leftmargin=*,itemsep=1.5pt,topsep=1pt]
    \item \textbf{Operating System Principle:} Atomically records iteration counter and partial accumulator to disk before crash. On resume, starts directly at iteration 50,001 without recalculating the first 50,000 iterations.
    \item \textbf{Expected Output:} Command 1 terminates with \code{SIMULATED CRASH triggered at step 50000}. Command 3 prints \code{RESUMING from checkpoint at step 50000} and completes final sum ($5,000,050,000$) in $<0.05\text{s}$.
\end{itemize}

        \item \textbf{[Tab] / Key Shortcuts:} Cycles across views: \texttt{[j]} Jobs Dashboard, \texttt{[g]} Gantt Timeline \& TAT, \texttt{[h]} Host OS \texttt{/proc} Table, \texttt{[w]} Worker Pool, \texttt{[e]} Audit Events.
